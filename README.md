# 🛍 Boutique Mirelle — Маркетплейс и Telegram-бот для воркеров

Полнофункциональная связка премиум-маркетплейса одежды и закрытого Telegram-бота для воркеров / партнеров (CRM-панель). Покупатели на сайте не знают о существовании бота, а воркеры получают уведомления о действиях, регистрациях и выплаты с покупок по их реферальным промокодам.

---

## 📸 Возможности бота и разделов

- **📦 Основное меню:**
  - 💭 **Общий чат** (ссылка настраивается через админку).
  - 💳 **Прямой перевод** (пополнение через Crypto Bot / ТП).
  - 🧾 **Проверка чека** (проверка заказов по номеру).
  - 💰 **Профиты** (ссылка на канал выплат/профитов).
  - 🤝 **Помощь в работе** (вопросы по работе идут Администраторам, помощь по клиентам — Кураторам).
  - 🎓 **Наставники** (список кураторов, подача заявок, отвязка после 5 профитов).
  - 🌐 **Полезное** (магазины и ресурсы команды, редактируются в админке).

- **👤 Профиль воркера:**
  - Никнейм, ID, баланс в долларах ($), замороженные средства.
  - Статистика профитов за день, месяц и всё время в рублях (₽).
  - 💸 **Оформить выплату**: вывод от **20$** через Crypto Bot на кошелек TRC-20.
  - 💸 **Перевод средств**: моментальный перевод между воркерами.
  - ⚙️ **Настройка**: привязка адреса кошелька USDT TRC-20.

- **🛒 Marketplace:**
  - Шапка с баннером, домены, ТП, промокод воркера со скидкой.
  - 👥 **Управление клиентами** (клиенты на сайте, реферальная ссылка, поиск, имена для переписки).
  - ⚙️ **Настройки сайта** (логи действий, залог, пополнение ТП, мои объявления, массовое уведомление, смена промокода).

- **👑 Админ-панель (ID 8391813279, 6667583896):**
  - 🖼 **Управление баннерами (Фото / Видео / GIF):**
    - Поддерживаются любые форматы: **Фото** (JPG, PNG), **Видео** (MP4), **GIF-анимация**.
    - Разделы: `🌟 Единый баннер`, `📦 Меню`, `👤 Профиль`, `🛒 Marketplace`, `🤝 Помощь`.
    - **Режим «Единый баннер»**: переключатель `ВКЛ / ВЫКЛ` — один баннер отображается на всех кнопках и разделах.
    - Быстрый сброс всех баннеров к стандартным.
  - 👥 **Управление персоналом (Роли):**
    - Назначение ролей Администратора, Модератора, Куратора/Наставника.
  - 🔗 **Настройки ссылок:**
    - Чат, канал профитов, магазины в «Полезное».
  - 📢 **Канал выкладки профитов:**
    - Указание Telegram ID или @username канала через Админ-панель.
    - Автоматическая публикация профитов при каждой покупке.
    - Ник воркера пишется **строго без @** + сумма профита в ₽ и $.
    - Кнопка тестовой отправки профита для проверки прав бота.
  - 💸 **Заявки на вывод:**
    - Выплата через Crypto Bot в 1 клик.
  - 📊 **Статистика и рассылка воркерам.**

- **🎓 Наставники / Кураторы:**
  - Куратор получает **20%** от покупок своего ученика.
  - Воркер получает **60%** (при наставнике) или **80%** (без наставника).
  - После **5 профитов** ученик может отвязаться от наставника и получать полные **80%**.
